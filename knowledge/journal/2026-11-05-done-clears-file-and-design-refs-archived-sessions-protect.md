# Done clears file and design refs; archived sessions protect nothing

When a story reaches done, Chough now drops every file and design reference from its checkpoint, and file retention ignores references held by archived sessions, since those sessions hold no proof by them (KNOW-21).

Both new tests failed first on main, then passed on Linux, one run each: done drops every file and design reference, and an archived session's file reference protects nothing.

The maintainer accepted PR #120 on 2026-11-05 with Record and merge, and the native review was recorded as a pass. The change was archived and the story closed done that day.
