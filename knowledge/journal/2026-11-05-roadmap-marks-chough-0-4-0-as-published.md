# Roadmap marks Chough 0.4.0 as published

The roadmap was updated to show Chough 0.4.0 as published, backed by an observation that the release installs cleanly.

A clean cargo install of chough 0.4.0 with --locked into an empty root on macOS arm64, using cargo 1.95.0, exited 0, and the installed binary reported version 0.4.0.

The maintainer accepted the roadmap change, PR #117, on 5 November 2026 with a request to record and merge it, and a passing review was recorded. The story closed as done the same day.
