# Checkout

## Intent

Sample intent for the Chough exercise, written as the shop owner might say it: "Orders of fifty dollars or more should ship free, and everyone else pays the normal fee."

## Criteria

- **CHECKOUT-1**  An order of fifty dollars or more ships free.
- **CHECKOUT-2**  An order under fifty dollars pays the standard shipping fee.
