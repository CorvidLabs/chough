# Checkout UI requirements

### REQ-checkout-ui-001

The checkout summary SHALL show "Free shipping" as the fee for an order of fifty dollars or more and the standard fee with the amount still needed below it. Trace: CHECKOUT-1, CHECKOUT-2.

### REQ-checkout-ui-002

The checkout summary SHALL show distinct loading, empty, error and submitting states that remain usable at 390 and 1280 pixel widths. Trace: CHECKOUT-1, CHECKOUT-2.
