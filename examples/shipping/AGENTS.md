# shipping (sample)

A disposable sample project for the Chough workflow. Use the Chough workflow skill
in `.agents/skills/chough-workflow/` or `.claude/skills/chough-workflow/`, and start
with `chough next --environment <env>`. HI owns intent, SpecSync owns the native
change, and Fledge or cargo runs checks. Never record a human approval or review
on anyone's behalf.
