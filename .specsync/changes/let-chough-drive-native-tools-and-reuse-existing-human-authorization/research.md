# Research

The current main skill tells the agent to do the work and forbids invented human
decisions. Its stage table and lifecycle Approval paragraph assume a fresh concrete
scope decision, while the README says Chough does not record approvals. Combined
with tool-specific recovery commands, the agent treated explicit implementation
authorization as insufficient and returned the native command to the operator.

The remedy is clearer current-agent ownership and applicable prior/standing
permission, with actual source and limits. It does not require proxy commands,
a model runtime, a cache of native authority, or a second lifecycle ledger.

Issue11/Grok41 supplies a separate actual ordering reproduction and correction;
this change does not duplicate it. Source-authoring tests can verify safe packaging
and preserved policy boundaries, but cannot establish how a fresh model will behave.
The earlier Kimi rubric stays frozen and its skipped proof stays not run.
