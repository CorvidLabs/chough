## MODIFIED

### REQUIREMENT REQ-cli-043

Knowledge directory built and kept current. With the librarian on, which is the default, `chough init` SHALL create the knowledge directory (`knowledge/`, or `library-dir`) with `index.md`, `journal/` and `lessons/`, built and bounded in memory first and written create-only, so an existing directory is preserved byte-identical and reported as `preserved`; when the index cannot be built or bounded, `chough init` SHALL still succeed, write no knowledge file and report the library as `refused` with the reason. `knowledge/index.md` SHALL be the vault's reading guide, generated from its sources: front matter with `id`, `title`, `type: guide` and `tags`; where to start, in plain words; the journal and its feed as the timeline of archived changes, with `.specsync/archive/changes/` linked for changes archived before the journal began (REQ-records-011), and the newest 10 posts; where things live, linking `hi/`, `specs/`, `.specsync/archive/`, `.chough/README.md`, `.chough/archive/sessions/` and `fledge.toml`; the open bugs, at most 20, blocking bugs first and then the newest by `created`, each linked, with their total and, when more are open, a link to `.chough/bugs/` and `chough bug list` named for the rest, so the number of open bugs never takes the index over its bound; the project's rule, skill, decision and policy files that exist and Git does not ignore (`AGENTS.md`, `CLAUDE.md`, `hi/AGENTS.md`, the installed and bundled workflow skill, `docs/DECISIONS.md`, each module's context and lesson source, `.specsync/sdd.json`); every lesson, linking each module's lesson source with its count of recorded lessons, every file in `knowledge/lessons/` and the newest 3 archived lesson bundles; and the existing `library/` snapshots and `briefs/`. It SHALL link and SHALL copy no text from what it links. When `chough stage advance` moves into done and its save succeeds, the helper SHALL, after the session's archive step (REQ-history-006), write the journal post of REQ-records-011 and then regenerate `index.md` and `feed.xml`, so right after the move the directory is what its sources generate and `chough library index --check` passes (KNOW-4). It SHALL report the result as `applied.librarian_index` with status `refreshed` and the index path, `skipped` with the librarian off, or `refused` with its reason. A refusal SHALL NOT undo or refuse the move into done, nothing SHALL be built with the librarian off, and no gate SHALL read the directory. Every Chough reader that lists or counts open native changes SHALL skip a directory under `.specsync/changes/` that holds no change files, such as one a branch switch left (#148). Trace: KNOW-1, KNOW-4, KNOW-5, KNOW-12, KNOW-15, KNOW-31, KNOW-33.

Acceptance Criteria
- With defaults, `chough init` reports the library `created`, writes `knowledge/index.md`, `journal/` and `lessons/`, and `chough next --json` names `knowledge/index.md`.
- With an existing `knowledge/index.md`, `chough init` reports `preserved` and leaves it byte-identical; with an index that cannot be bounded, `chough init` succeeds, reports `refused` naming the 65536-byte bound, and leaves no knowledge directory.
- With defaults, `stage advance` into done writes the journal post, reports `librarian_index` `refreshed`, and `library index --check` passes right after it with no command in between, in a project that had no knowledge directory.
- `knowledge/index.md` links at most 20 open bugs, blocking first and then the newest, states their total, and links `.chough/bugs/` and names `chough bug list` when more are open. It links every rule, skill, decision and policy file that exists and Git does not ignore, and none that is missing or ignored.
- With 1,500 open bugs, `chough library index` builds the index within the 65,536-byte bound and `library index --check` passes.
- `knowledge/index.md` links each module's lesson source with its lesson count, every file in `knowledge/lessons/`, the newest 3 lesson bundles, the journal, its feed and `.specsync/archive/changes/`, and holds no lesson, criterion or requirement text.
- With the librarian off, `stage advance` into done writes no post, reports the index `skipped`, creates no knowledge directory, and done is still recorded.
- After a branch switch leaves an empty `.specsync/changes/<id>/deltas/`, `library index`, `next`, `gate list` and `doctor` treat it as no open change, and `library index --check` passes in a fresh clone of the same commit (#148).
- In a repository whose `.gitignore` ignores `.grok`, after `chough init --host grok` and a commit, the index links nothing under `.grok/`, and `library index --check` passes in the working tree, with the ignored skill copy present or removed, and in a fresh clone (#245).
