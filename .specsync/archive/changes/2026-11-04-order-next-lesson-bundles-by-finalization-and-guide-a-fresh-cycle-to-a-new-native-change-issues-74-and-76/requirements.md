# Requirements

MODIFIED REQ-cli-021 (see `deltas/cli.md`). `chough next` names the newest 3 archived
lesson bundles by recorded finalization timestamp, then directory, the order the
librarian uses for its hot archives, instead of 5 by directory name. An archived change
finalized no later than the latest reset is the previous cycle's, so before done the next
valid action keeps the reset's guidance and names `specsync change new` instead of the
archived refusal or another reset. With no native change recorded, a refused
no-native-change gate names `specsync change new` instead of a bare status read.
