# Docs

REQ-cli-054, REQ-cli-021, and REQ-cli-052 say which session a blocking bug stops. The stage skill, the bug skill, the FRD, the lifecycle diagram, and the CLI reference say the same. An unrelated blocking bug is named and does not stop the session.
