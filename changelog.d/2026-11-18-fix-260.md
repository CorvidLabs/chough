- A new record whose write fails part way, as on a full disk or past a file size limit,
  is no longer left behind. `chough bug add` and `chough journal add` used to leave an
  empty file that made `bug list`, `status` and `next` fail until it was removed by
  hand, or a cut-off record the readers accepted. A new file is now written to a
  temporary file first and linked to its name only when it is whole, so a failed write
  leaves nothing at the name and never removes a file another writer put there (#260,
  REQ-records-001).
